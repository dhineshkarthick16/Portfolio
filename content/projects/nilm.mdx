## 📌 Project Overview

**EdgeWatt** is a cloud-free Non-Intrusive Load Monitoring (NILM) solution designed to disaggregate electrical appliance usage across an entire facility using a single split-core current transformer (CT clamp) attached at the main panel.

By eliminating the need for individual smart plugs per appliance or heavy cloud GPUs, EdgeWatt processes raw current waveforms on a dual-core ESP32 microcontroller using FreeRTOS. It combines a 13-dimensional steady-state feature extraction pipeline with dynamic thermal drift compensation ("SET AS NO LOAD") to achieve sub-millisecond local inference while maintaining complete user data privacy.

## ⚡ Key Features & Novelty

* **Edge-Native Inference:** Executes a Scikit-Learn soft-voting ensemble model directly on an ESP32 in **<0.8 ms** per window.
* **Dynamic Thermal Drift Offset:** Features real-time baseline subtraction ("SET AS NO LOAD") to eliminate zero-point sensor drift caused by ambient temperature changes.
* **Low-Power Load Disambiguation:** Leverages higher-order statistical moments and harmonic variance to separate overlapping low-wattage SMPS and resistive loads (e.g., ~8.5W phone charger vs. ~17W incandescent bulb).
* **Sub-$5 Hardware Overhead:** Built entirely on open-source, commodity components rather than expensive proprietary ARM Cortex platforms.
* **Privacy-Preserving Telemetry:** Operates 100% locally with dual outputs: real-time appliance status on an I2C 16x2 LCD and remote monitoring via a Streamlit dashboard.

## 🛠️ Hardware & Signal Chain

- **Current Sensing:** SCT-013 non-invasive current transformer clamp (100A/50mA) with burden resistor converting induced secondary current to AC voltage.
- **Active DC Bias (+1.65V):** LM358 operational amplifier configured as a unity-gain buffer to establish a low-impedance virtual ground, centering AC waveforms within the ESP32's 0V–3.3V ADC input window.
- **Galvanic Zero-Crossing Detection:** 4N35 optocoupler isolated from high-voltage line, generating digital interrupt pulses on mains voltage zero crossings for precise phase-angle alignment.
- **Edge Compute Engine:** ESP32 Xtensa Dual-Core 32-bit MCU (Core 0: DMA/FreeRTOS continuous ADC sampling; Core 1: 13-D feature extraction and sub-ms ensemble classification).

## 📊 Dataset Specifications

The project relies on **2 core hardware-validated datasets** collected directly from the physical sensing setup, totaling **10,200+ recorded samples**:

1. **Multi-Regime Steady-State Dataset (8,000+ Samples):** Raw 12-bit ADC waveform logs, 13-D feature vectors, and power estimates across isolated and combined appliance states (resistive, inductive, capacitive, and SMPS non-linear load signatures).
2. **40-Minute Dynamic Switching Stress Test Dataset (2,200+ Samples):** Continuous multi-appliance switching sequence yielding verified **91.8% dynamic tracking accuracy** under real-world electrical noise.
